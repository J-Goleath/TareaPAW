## Contenido

- **Tarea 2:** el tipo de cambio se carga con JavaScript (`site.js`), con caché en `localStorage`, en una tarjeta flotante arriba a la derecha.
- **Tarea 3:** proyecto `PAW.MinimalAPI` con los endpoints de Tasks (GET, POST, PUT, PATCH, DELETE), con los datos inyectados por Dependency Injection (sin DbContext), y la pantalla **Tasks** en `PAW.Web`.

## Cómo ejecutar

1. Abrir `PAW.sln` en Visual Studio 2022.
2. Configurar varios proyectos de inicio: `PAW.Web`, `PAW.MinimalAPI` y `PAW.API`.
3. Ejecutar con F5.
